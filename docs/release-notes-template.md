## TermVox release

Pre-built binaries for Linux, macOS, and Windows. Install without Rust:

```bash
curl -fsSL https://raw.githubusercontent.com/Jeronimo0228/termvox/main/scripts/install.sh | bash
```

Or download the archive for your platform below and verify the `.sha256` checksum.

See [Installation](https://github.com/Jeronimo0228/termvox/blob/main/docs/installation.md) and [Daemon mode](https://github.com/Jeronimo0228/termvox/blob/main/docs/daemon.md).
