# TermVox for VS Code / Cursor

The editor extension now lives inside the npm package:

```bash
npm install -g termvox
termvox-editor-install
```

Source for development: [`packages/termvox/editor`](../packages/termvox/editor).

## Develop locally

```bash
cd packages/termvox/editor
npm install
npm run compile
```

In VS Code or Cursor: **Extensions → … → Install from Location…** and select
`packages/termvox/editor`.
